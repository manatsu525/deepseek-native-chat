# Skill management

Use `skill_list` before changing the installed set. Read a Skill's `SKILL.md`
with `skill_read` when its behavior matters. Install from a Git repository or
local directory with `skill_install`; newly installed Skills are enabled by
default. Use `skill_enable` to toggle a Skill and `skill_remove` only for a
user-installed package. Skills provide instructions and optional resources;
the Agent's host tools provide the actual capabilities.
