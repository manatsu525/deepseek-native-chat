# Requesting code review

After implementation, inspect the diff and ask for a review of correctness,
regressions, security-sensitive behavior, and missing tests. Summarize changed
files, checks run, failures, and any deliberate trade-offs. A review is a
verification step, not a reason to rewrite working code without evidence.
