# Writing plans

Use this for changes that touch more than one file or have meaningful behavior.
Inspect the repository first. Write a concise plan with the target files, the
observable behavior, and the verification command. Keep the plan proportional:
do not delay a small safe edit for a long design document. Once the next useful
operation is known, perform it with a host tool.
