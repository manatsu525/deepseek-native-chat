# Test-driven development

For a reproducible bug or new public behavior, add or identify a focused test,
make it fail for the right reason, implement the smallest fix, then run the
focused and relevant broader tests. For exploratory UI work where an automated
test is not useful, use a concrete browser or syntax check instead.
