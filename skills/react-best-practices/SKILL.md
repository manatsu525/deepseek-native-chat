# React and Next.js practices

Keep data fetching close to the server boundary where appropriate, avoid
unnecessary client components and waterfalls, memoize only measured hot paths,
use stable keys, handle loading/error/empty states, and keep effects focused on
external synchronization. Preserve accessibility and test the user-visible
behavior rather than implementation details.
